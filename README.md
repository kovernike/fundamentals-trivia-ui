# Trivia UI

Interactive trivia application built with HTML, CSS and JavaScript.

The app allows users to select a trivia category, fetch questions from an external API, answer multiple-choice questions and track their score.

## Tech Stack

- HTML
- CSS
- JavaScript
- Fetch API
- JavaScript modules

## Features

- Category selection screen
- Dynamic question rendering
- Multiple-choice answers
- Answer validation
- Score calculation
- Basic state management with JavaScript modules
- Responsive UI structure

## What I Practiced

- DOM manipulation
- Consuming external APIs with `fetch`
- Organizing JavaScript code into modules
- Handling user interactions and form submissions
- Managing application state without a framework
- Separating responsibilities between data, UI and utilities
